## 해석 메모

- **무효 실행이다.** "2000 RPS까지 통과"는 사실이 아니다. 목표 속도로 요청이 나가지 않았다.
  - 전체 반복 376,425번 중 221,257번(59%)이 요청 없이 건너뛰었다. 요청 실패 24건 때문에 VU 24개가 토큰을 잃었고, 그 VU는 이후 요청을 보내지 않았다. 요청이 줄었으니 실패율은 0%로 보였다.
  - 예: 1600 RPS 단계는 약 88,000건이 나가야 하는데 16,739건만 나갔다.
- **단계 이름표가 어긋났다.** 준비 단계(사용자 1,000명 로그인)에 걸린 시간만큼 k6의 경과 시간이 앞서서, 단계별 p95와 서버 지표가 실제 단계와 어긋났다. (스크립트에서 준비가 끝난 시각 기준으로 계산하도록 고침)
- 실패 요청 24건의 상태 코드는 이 실행에서는 집계하지 않아 알 수 없다. 스크립트에 상태 코드별 집계를 추가했다.
- 고친 스크립트: 실패하면 다시 로그인해서 토큰을 되찾아 이어가고, 단계별 "도달률"과 "미달" 판정을 추가했다.
